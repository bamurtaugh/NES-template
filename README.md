# NES Template Repository

This repository contains sample code for demonstrating **Copilot Next Edit Suggestions (NES)** capabilities. It provides a collection of realistic code scenarios across multiple programming languages to showcase how NES can assist with various development tasks.

## Overview

The repository is organized into progressive examples that demonstrate different types of code editing patterns:

### 1. Changing Intent (`1-Changing_Intent/`)
Examples demonstrating how to modify code behavior and purpose:
- `geometry.ts` - TypeScript geometric calculations
- `stats.cpp` - C++ statistics functions

### 2. Adding Logic (`2-Adding_Logic/`)
Examples showing how to add new functionality to existing code:
- `extension-sample/` - VS Code extension Hello World sample
- `game.py` - Python game logic

### 3. Changing/Fixing Logic (`3-Changing_Fixing_Logic/`)
Examples of debugging and logic corrections:
- `js-game/` - JavaScript game application
- `scenarios.ts` - TypeScript scenario handling

### 4. Refactoring (`4-Refactoring/`)
Examples demonstrating code restructuring and improvement:
- `java-sample/` - Java application refactoring examples

### 5. Fuller Examples (`5-Fuller/`)
Complete, feature-rich applications for advanced demonstrations:
- `task-manager-app/` - Full React/TypeScript task management application

## Getting Started

Each subdirectory contains its own sample code with specific scenarios. Navigate to individual directories for detailed README files with specific use cases and examples.

### Task Manager App

The most comprehensive example is the Task Manager app in `5-Fuller/task-manager-app/`, which includes:
- React and TypeScript implementation
- State management with Context API
- Custom hooks for filtering and sorting
- Complete CRUD operations
- Multiple demonstration scenarios for NES

See the [Task Manager App README](5-Fuller/task-manager-app/README.md) for detailed scenarios and usage examples.

## Purpose

This template repository serves as a demonstration and testing ground for Copilot's Next Edit Suggestions feature, providing realistic code examples that showcase NES capabilities across different:
- Programming languages (TypeScript, JavaScript, Python, C++, Java)
- Development scenarios (new features, bug fixes, refactoring)
- Application types (extensions, games, web apps)
